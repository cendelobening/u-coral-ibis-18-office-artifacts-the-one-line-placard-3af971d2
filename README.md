One line, at most 180 characters: a museum placard for an ordinary office object, written as if the object were an ancient artifact from a lost civilisation. A stapler becomes a ritual object of the Binding Rite — catalogue date, material, donor, and all.

## Run it

```sh
python3 main.py
```

Writes the placard to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
